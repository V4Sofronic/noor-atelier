# Noor Atelier – Eastern Wear Fashion Store

A luxury Eastern wear storefront featuring bridal fashion, formal wear, party outfits, everyday clothing, and more. Noor Atelier combines elegant design with interactive shopping features, animated visuals, and bilingual English/Urdu support.

## Features

- Animated bridal hero with a slow-dissolve frame sequence
- Luxury burgundy and champagne-gold theme
- 10 fashion categories
- 95 products with product photography
- Interactive shopping cart with quantity controls
- Cart persistence between visits
- WhatsApp ordering for individual products and full cart
- English and Urdu language support
- Right-to-left (RTL) layout for Urdu
- Animated product cards with 3D hover tilt effects
- Responsive layout for mobile, tablet, and desktop

## Fashion Categories

Bridal, Formal, Party Wear, Casual, Winter, Abayas, Kids, Menswear, Shawls & Dupattas, and additional collections.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Local image assets
- WhatsApp ordering integration

## Run Locally

1. Download or clone the repository.
2. Keep `index.html` and the `images` folder together.
3. Open `index.html` in your browser.

No installation or build process is required.

## Deployment

This is a static website and can be deployed using **Cloudflare Pages**.

Deployment guide: `docs/DEPLOY-CLOUDFLARE.md`
